# Diretório `ready/` (Homologação Final)

**O que fazer aqui:**
Esta é a pasta de homologação e conferência final. Os arquivos localizados nesta pasta já passaram pela mesa de revisão (`../review/`), tiveram seus metadados, formatação e tipografia validados, e estão 100% prontos para publicação.

**Como trabalhar com esta pasta:**
- Mova para cá os arquivos de `../review/` que foram completamente revisados e aprovados.
- **Validação:** Execute `uv run openscimd validate` para certificar que todos os requisitos técnicos estão cumpridos.
- **Próximo passo:** Transfira os arquivos finais homologados para suas respectivas pastas oficiais em `content/articles/` ou `content/books/` e execute `uv run openscimd index` para atualizar o catálogo.
